# Aula 4 - Cadastro de Alunos

Projeto Java Desktop desenvolvido na disciplina Desenvolvimento de Sistemas.

## Como executar
1. Abrir o projeto no Eclipse.
2. Executar a classe br.edu.ceub.ds.aula04.app.Principal.

## Estrutura
- model: classes de domínio.
- service: regras e operações sobre a lista.
- view: interface Swing.
- app: classe que inicia o programa.
